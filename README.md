# Playwright Automation Engineering Portfolio

A portfolio project demonstrating practical software testing and test automation engineering using Playwright and TypeScript.

## Project Goals

- Build a maintainable Playwright automation framework.
- Apply the Page Object Model (POM).
- Implement reusable fixtures and test utilities.
- Combine UI and API testing.
- Use data factories and schema validation.
- Improve test reliability and debugging.
- Generate and analyze test reports.
- Integrate automated tests into GitHub Actions CI.

## Application Under Test

- Main application: https://automationintesting.online/
- Additional API playground: https://restful-booker.herokuapp.com/apidoc/index.html

## Technology Stack

- TypeScript
- Playwright Test
- Node.js
- API Testing
- Git and GitHub
- GitHub Actions
